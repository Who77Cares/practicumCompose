Здесь в папке собраны основные компоненты анимации, которые так или иначе
были использованы в проекте BioCards

1. Collapsible Toolbar - верхняя шторка, скрывающаяся при скролле вниз
    и открывающаяся при скролле вверх

2. SelectableChipItem - плавная, приятная анимация при клике
    на элемент с изменением цвета и размера
    +
    пример как нужно правильно заполнять параметры компоуз-функции

3. ThreeCheckboxElements - а. Обычный чек-бокс, б. Radio-чек-бокс, в. Слайдер-ползунок, г. Выбор-анимация из трех табов

4. SixteenAnimations - 16 (!!!) крутых анимаций при клике

5. EnterExitAnim - 9 анимаций появления\исчезновения элемента и одна такая анимация для списка

6. FromOneToThreeFab - одна нижняя кнопка. При нажатии появляются еще
    три кнопки (кликабельны). При повторном нажатии на родительскую кнопку -
    дочерние также красиво заезжают обратно
