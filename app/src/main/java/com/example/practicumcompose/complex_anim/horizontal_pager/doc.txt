HorizontalPager - список элементов в одном компоуз, которые можно свайпать влево-вправо.
сам H.P довольно простой - это переменная pagerState + HorizontalPager
 - в файле помимо H.P реализован верхний список (TopScrollRow) - при клике на элемент списка
    нас переносит на конкретный pager. При свайпе на другой pager происходит
    автоматический перенос на элемент списка TopScrollRow.
